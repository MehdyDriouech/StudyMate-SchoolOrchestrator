Points d'entrée clés
--------------------
1. index.html → Charge tous les modules
2. js/app.js → Initialise le routing et l'app
3. js/app-service.js → Intercepte les appels API
4. js/demo/FakeRouter.js → Retourne les mocks

Flow d'exécution
----------------
1. Chargement index.html
2. Import des modules ES6
3. app.js démarre (DOMContentLoaded)
4. Vérification isDemoSession()
5. Si pas de session : view-auth
6. Clic "Découvrir la démo" → startDemoSession()
7. Reload → isDemoSession() = true
8. Navigation vers view-dashboard-teacher
9. Appel api.get('/stats/overview')
10. FakeRouter intercepte et retourne mock
11. Rendu du dashboard avec données
